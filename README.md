# kvr-vishnu.github.io

Source of [kvr-vishnu.github.io](https://kvr-vishnu.github.io), my personal site.

One static HTML file, no framework, no build step needed to serve it. Fonts come from Google Fonts. No cookies and no analytics.

The handwritten name at the top is replayed from single-stroke pen paths (`assets/signature.json`, generated from a Hershey script font). The two traces under it are the second difference of those same points, which is the shape of signal an accelerometer in a pen would record. Nothing in the animation is a stock image or a fake chart.

`.nojekyll` is there so GitHub Pages serves `.well-known/security.txt`.
